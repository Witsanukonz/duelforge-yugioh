# Site soundtrack

Place legally obtained MP3 files here using these exact filenames:

- `gods-anger.mp3`
- `track-02.mp3`
- `track-03.mp3`
- `track-04.mp3`
- `track-05.mp3`

You may add between one and five files. Missing slots are skipped automatically.
The player starts automatically when the browser permits it; otherwise it starts
after the visitor's first click. Playback continues to the next available track
and loops back to the first track after the playlist ends.
